# Portfolio

This is a personal portfolio website built with React and Framer Motion. It showcases your work, skills, and contact information in a modern, responsive layout.

## Features

- **Animated Navbar:** Smooth scrolling navigation with Framer Motion animations.
- **Responsive Design:** Works well on both desktop and mobile devices.
- **Sectioned Layout:** Includes Home, About, Work, and Contact sections.
- **Easy Customization:** Update your information, images, and projects easily.

## Getting Started

1. **Install dependencies:**
   ```sh
   npm install
   ```

2. **Start the development server:**
   ```sh
   npm start
   ```

3. **Open your browser:**  
   Visit [http://localhost:3000](http://localhost:3000) to view your portfolio.

## Customization

- **Logo:** Replace `Screenshot_2025-08-03_003057.png` in `public/assets/` with your own logo.
- **Sections:** Edit the components in `src/Components/` to update your content.
- **Styling:** Adjust CSS classes or add your own styles for a unique look.
